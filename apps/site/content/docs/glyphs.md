![Set Glyph: 17 glyphs in four groups](set-glyph.png)

**Toucan: Set Glyph** picks the status bar shape, previewed as you move through the list: one of 17 in Toucan's own style, drawn for 16 pixels. A repository needs a color first. The default is `square`; set another one with the command or with `glyph` in [`toucan.repos`](/docs/settings#toucanrepos).
