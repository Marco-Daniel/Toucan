# 0001. Present Toucan as a showcase first

- Status: Accepted
- Date: 2026-10-03
- Deciders: Marco

## Context and Problem

With the feature set essentially complete, the next work depends on who Toucan is for: Marco alone, other users through the Marketplace, or a public showcase of the way it's built.

## Considered Options

- Just for Marco: small comforts and upkeep
- Other users: publish to the Marketplace and Open VSX
- A showcase: make the repo and README tell the story

## Decision Outcome

Chosen: a showcase, starting with the README: show what Toucan does, visually and completely. More glyphs and Marketplace publishing stay possible later.

## Consequences

- Good: The repo explains itself to anyone who lands on it.
- Bad: No new features in this iteration.
