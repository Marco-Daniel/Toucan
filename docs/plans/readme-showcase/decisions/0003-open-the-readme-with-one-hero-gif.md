# 0003. Open the README with one hero GIF

- Status: Accepted
- Date: 2026-10-03
- Deciders: Marco

## Context and Problem

A still image can't show Toucan's main idea: windows changing color as focus moves, and the live preview.

## Considered Options

- A hero GIF at the top, stills for the rest
- Stills only
- GIFs for every flow

## Decision Outcome

Chosen: one short hero GIF at the top (e.g. three windows in different colors with focus moving, plus Set Color's live preview), recorded by the same script; stills everywhere else.

## Consequences

- Good: The first impression shows the behaviour, not just a state.
- Bad: A GIF is heavier than a still; keep it short and small.
