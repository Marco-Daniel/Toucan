# 0004. Document every feature in the README, with screenshots

- Status: Accepted
- Date: 2026-10-03
- Deciders: Marco

## Context and Problem

The README lists the commands and settings, but doesn't show them.

## Considered Options

- One section per command and setting, each with a screenshot
- Keep the current lists

## Decision Outcome

Chosen: one section per palette command and setting, plus the status bar, the sidebar block and the experimental search emoji, each with a screenshot from the script.

## Consequences

- Good: A complete visual tour of the extension.
- Bad: A longer README to keep in sync, which docs-sync and the script cover.
